# Blue Launch - Landing Page

Sitio web oficial para la entrega final del proyecto **Blue Launch**.

## 🚀 Publicación en GitHub Pages

1. Crea un repositorio en GitHub (ej. `blue-launch-landing`).
2. Descomprime estos archivos e súbelos a la rama principal (`main` o `master`).
3. Ve a **Settings** > **Pages** en tu repositorio de GitHub.
4. En **Source**, selecciona `Deploy from a branch` y escoge `main` (`/root`).
5. Guarda los cambios. ¡Tu sitio estará en línea en un par de minutos!
